title: Scriptr Editor
description: Integrate the reusable Scripture-aware editor without coupling your application to its development harness.
---

Scriptr Editor provides rich-text editing, portable canonical documents, Scripture references and comparisons, lightweight annotations, media blocks, extension seams and read-only rendering.

Your application owns storage, authentication, workspaces, routing and synchronization. The editor receives only the capabilities it needs through typed props and provider contracts.

The package is under development. These guides describe the current implementation, not a published replacement release or a guarantee of exhaustive browser certification.

## Start here

## Public entry points

| Entry point                 | Purpose                                                   |
| --------------------------- | --------------------------------------------------------- |
| `scriptr-editor`            | Configuration and presentation contracts                  |
| `scriptr-editor/document`   | Canonical documents, validation, migration and transforms |
| `scriptr-editor/commands`   | Command catalogue                                         |
| `scriptr-editor/host`       | Typed provider and host capabilities                      |
| `scriptr-editor/scripture`  | Addresses, normalized datasets and provider transport     |
| `scriptr-editor/extensions` | Persisted extension registration and migration            |
| `scriptr-editor/react`      | Completed editor, renderer and feature components         |
| `scriptr-editor/server`     | Framework-neutral Scripture transport handler             |
| `scriptr-editor/styles.css` | Compiled editor styles, motion and scrollbar defaults     |

Base shadcn controls are private implementation details. Build your application's controls in your own component library; do not import the editor's internal Select, Dialog or Button modules.
